# OSClub Website

Local Next.js (App Router) landing site for **OSClub** — Open Source Club.

- Domain: [https://osclub.org](https://osclub.org)
- Stack: Next.js + TypeScript + Tailwind CSS

## Run locally

```bash
cd osclub-website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/about` — About the club
- `/projects` — Projects
- `/join` — How to get involved

## Deploy

GitHub repo + Vercel. Domain: osclub.org.
